# 2d-game-practice
2D Game built to serve as a refresher in Godot 


Decided to code the game in C# over GDscript as I wanted to develope my skills in this language further and become more familiar in a day to day use case. 

This project was built using the Godot tutorial docmentation which you can find here: 
https://docs.godotengine.org/en/stable/getting_started/first_2d_game/index.html


I do not claim this as my own work, merely a small project to re-familiarize myself with Godots 2D engine and get abasic refresher into C#
